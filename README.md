# Kemp-Tenenbaum form discovery: MATLAB to Python

A test-driven translation of Charles Kemp's `formdiscovery1.0` MATLAB code, which implements
the structural form discovery model from:

> Kemp, C., & Tenenbaum, J. B. (2008). The discovery of structural form. *PNAS*, 105(31), 10687–10692.

The model fits graph structures (partitions, chains, orders, rings, hierarchies, trees, grids,
cylinders) to feature, similarity, or relational data and returns the best structure of each
form together with its posterior probability.

## Approach

- Every MATLAB function is translated bottom-up and verified against the original code running
  in GNU Octave on identical inputs. Golden fixtures generated by Octave are committed so tests
  run without Octave; live Octave-vs-Python parity tests run when it is installed.
- Deterministic code (utilities, priors, graph construction, likelihoods) must match Octave to
  near machine precision. Search heuristics are compared with replayed random permutations.
  Values downstream of the branch-length optimiser are compared by optimality within a
  documented tolerance.
- The Graphviz display code (`draw_dot` and friends) is ported first to pygraphviz, then to
  networkx and matplotlib.

See `PLAN.md` for the full plan, hazards, and milestones.

## Running the work loop

```
cd RalphLoops/loop0001
python3 loop.py 1        # one iteration
python3 loop.py 10       # ten iterations, unattended
```

Each iteration starts a fresh agent session, works on the first unchecked item in
`iterations.md`, runs the regression gate `python -m pytest -q -m "not slow"`, and commits.
